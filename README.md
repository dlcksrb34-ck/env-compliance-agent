## 🏛️ 대한민국 6대 핵심 환경법 지원 체계

1. **🟢 화학물질관리법 (화관법)**: 2025년 최신 전면 개정판 100% 완전 가동 (차등관리제, 방류벽 110%, 세안기 15~35℃, 15대 과태료/처분)
2. **⚪ 화학물질등록평가법 (화평법)**: 서비스 준비 중 (1톤 이상 물질 등록, CBI 국외대리인)
3. **⚪ 대기환경보전법 (대기법)**: 서비스 준비 중 (배출시설, 굴뚝TMS, 자가측정)
4. **⚪ 물환경보전법 (수질법)**: 서비스 준비 중 (폐수배출시설, 특정수질유해물질, 완충저류)
5. **⚪ 폐기물관리법 (폐기물법)**: 서비스 준비 중 (지정폐기물, 올바로시스템, 보관기한)
6. **⚪ 환경오염시설통합관리법**: 서비스 준비 중 (20개 업종 BAT 통합허가)

## 🚀 다른 PC에서 실행하는 초간단 3단계 방법

### 1단계: 프로젝트 폴더 복사
현재 컴퓨터의 `env-compliance-agent` 폴더 전체를 USB나 압축파일(ZIP)로 다른 PC에 복사합니다.

### 2단계: Node.js 설치 (최초 1회)
다른 PC에 **Node.js LTS 버전**([https://nodejs.org](https://nodejs.org))을 설치합니다.

### 3단계: 원클릭 실행 (`start.bat`)
복사한 폴더 안에서 **`start.bat`** 파일을 더블 클릭하면 모든 준비가 끝나고 브라우저(`http://localhost:3000`)가 자동 실행됩니다!
